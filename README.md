One joke about cats, one line (125 characters), written by `main.ts` to `/output/entry.txt`.

> My cat left a dead mouse on my pillow this morning. I said thank you. He brought two the next day — apparently I tipped well.

## About

A one-line cat joke with a setup and a turn that lands: the cat leaves a
dead mouse on the pillow — the classic unwanted "gift" every cat owner
knows — the owner thanks him, and the punchline reframes the thanks as a
restaurant tip, so the cat upsells his owner with a second mouse the next
day. Three beats, no padding, no explanation after the punchline — a joke
you would retell to a friend the same day.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/mf_catjoke_v3 node main.ts
cat /tmp/mf_catjoke_v3/entry.txt
```
